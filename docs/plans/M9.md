# M9 plan: interpolation and variable fonts

_Planning pass of 2026-10-11. Status: **accepted**, with the answers in § 7 decided by the orchestrator on the owner's behalf._

M9 makes the designspace work. It adds axes, axis locations and axis mappings, intermediate
(brace) layers, virtual masters and alternate (bracket) layers; the compatibility check and its
indicators; static instances between and beyond the masters (the M2 plan's deferred "instances
between masters"); variable TrueType fonts with `fvar`, `avar`, `gvar`, `HVAR`, `VVAR`, `MVAR`,
`STAT` and feature variations, with variable kerning and mark positions; the variable syntax of
feature code; CFF2 as an extra flavour; opening variable fonts; and the editor's side: the master
switcher in the toolbar, the Preview of instances, the Master Compatibility view, the special
layers in the Layers palette, the interpolation dialogs and the Compare Fonts and Compare Family
windows. fontc and fontmake are the oracles for every table; fontmake is also the oracle for
static instances and for the variable feature syntax.

## 3. Answers and decisions

### Design decisions

| Question | Answer for M9 |
|---|---|
| Where interpolation lives | A new crate `interp` (L2: `model`, `geom`), as `docs/architecture.md` plans it: the designspace (axes, ranges with virtual masters, internal and external coordinates, normalisation, the origin, variable font settings and Disable Masters), glyph sources (master and intermediate layers with resolved locations, alternate sets), the compatibility check, interpolation of every master-bound value, static instance fonts, the overlay of alternate ranges. Pure functions; no I/O |
| Static instances | `interp::instance_font(font, instance)` returns a font with one master at the instance's location (glyphs, metrics, stems, number values, kerning, interpolable parameters); `compile` resolves that master as today. `Font::resolve` keeps refusing instances between masters, so the model does not depend on `interp` |
| The variation model | `fontcraft_geom::variation` for both Font Type settings (guess on `fontInfo.fontType`), anchored at the variable origin; per-glyph sub-models for glyphs with intermediate layers or missing masters, cached by the set of locations. `geom` gains `VariationModel::sub_model` |
| Coordinates | Internal everywhere in the model and commands; external only at the table boundary (`fvar`, `avar`, `STAT`, feature variations through the map) and when a command asks for it (`coordinates: external`) |
| Alternate layers | One range set per distinct `axis_rules`; both bounds inclusive; static instances switch by the range at their location; variable fonts get `<glyph>.BRACKET.varAltNN` glyphs and feature variations in the feature § 7 question 2 decides, as both oracles write them |
| Origin | By § 7, question 3; the recommendation is the handbook's first master |
| Composites in variable fonts | Kept where `gvar` can vary them; decomposed when component transforms other than offsets differ between masters (`compile.inconsistentComponentsDecompose`), when Decompose Components in Variable Font is on, and for composites of glyphs with intermediate layers as § 7 question 4 decides |
| Curves | cubic to quadratic across all sources of a glyph at once (fontTools' `curves_to_quadratic`, MIT, ported into `geom` with credit), so every master gets the same points |
| STAT | fontc's derivation (`glyphs2fontir/src/stat.rs`, Apache-2.0) ported with credit into `compile/src/var/stat.rs`; written for every variable font unless every setting turns Export STAT Table off; never format 4 |
| Variable kerning and marks | per master values turned into a default plus deltas through `VariationStoreBuilder`, written as `PendingVariationIndex` device tables and a `GDEF` variation store, by the M5 and M6.17 writers in `features` |
| Variable feature syntax | M9.11 lowers the reference's syntax to the feature-file form, as glyphsLib does: `#ifdef`/`#ifndef VARIABLE` kept or dropped, each `condition` to a `conditionset` and `variation` block, `(tag:coord)` values to scalars, number tokens to per-location values; M9.12 compiles the result with M8's fea-rs build, giving it `interp` through fea-rs's `VariationInfo` trait |
| Extrapolation | By § 7, question 6; the recommendation is to extrapolate static instances, as the handbook says, and to leave extrapolated instances out of variable fonts |
| Compatibility scope | Masters with a non-zero scalar at some instance's location, plus every master of a variable font setting not disabled; Enforce Compatibility Check on widens it to all masters, off hides the indicators |
| Caching | The engine keeps one `interp` designspace and one compatibility table per font revision, rebuilt for the glyphs a command changed; the preview's instance glyphs are cached per glyph `Arc` and instance |
| Undo | Every font-changing command is one undo step; a refused command leaves the font pointer-equal. Removing or reordering an axis rewrites every location in the same step |
| What we depend on | write-fonts, read-fonts, skrifa and font-types (already in the workspace); fea-rs through M8. Not fontc, fontir or fontbe; fontdrasil only inside `fea`, for the coordinate and axis types fea-rs's `VariationInfo` names. Decision 0002 keeps fontc as an oracle and a bootstrap backend through the file format, and its internal representation is its own to change. Ported with credit (file header and `NOTICE`): fontc's `stat.rs` and its `gvar`, `HVAR`, `MVAR` and `avar` assembly where they set a rule we must match; fontTools' `overlayFeatureVariations`, `curves_to_quadratic` and `VariationModel.getSubModel` (MIT); glyphsLib's variable feature converter (Apache-2.0) as the model for M9.11 |
| Bootstrap backend | Decision 0002 item 3 stays available: if M9.5's measure is far from fontc's output, the owner may make fontc (through `.glyphs` text) the default for variable TrueType export and keep ours for preview |

### Limits (never crash)

| What | Limit |
|---|---|
| Axes | `MAX_AXIS_VALUES` (64) per font, coordinates and rules per layer; tags four printable ASCII characters |
| Masters, virtual masters, sources per glyph | `geom::variation::MAX_MASTERS` (1,024) in all; virtual masters at most 64 |
| Instances and variable font settings | 4,096 per font; named instances in `fvar` at most 65,535 by the format |
| Alternate range sets per glyph | 64; feature-variation records after overlay at most 4,096, with the overlay's work bounded by a budget (it can grow exponentially with overlapping boxes) |
| Axis mapping points | 256 per axis; mappings must be finite and increasing on both coordinates, else refused at the command and ignored with a warning at export |
| Coordinates and values | finite, within ±`MAX_COORDINATE`; non-finite inputs refused before any model call |
| Variation model work | regions per glyph bounded by its sources; per-glyph sub-models cached; deltas per glyph bounded by `MAX_TT_POINTS` |
| gvar | shared tuples at most 4,095 (format); tuple variations per glyph at most 4,095 (format) |
| Feature code | condition sets 4,096; alternatives in one variable value 64; the preprocessor's input bounded by M8's feature-code size limit |
| Generate Instances | at most 256 documents per run |
| Compare Family | documents open at once (the session's limit) times `MAX_GLYPHS` rows, built lazily |
| Opening variable fonts | regions and named instances capped as above; tuple counts and point counts read from the file checked before allocation |

entries on 32 M9 rows, all new. With them the inventory goes from 678 guesses on 435 rows to 712
on 467. `docs/parity.md` and `docs/guesses.md` are regenerated by M9.0. Each guess names what
would settle it; § 8 turns them into checks. The ones with the most effect:

  `masters.originAutomaticForStatic`.

  `interpolation.checkCompatibility`, `view.showMasterCompatibility`.

  `fontInfo.customParameters.masterInterpolation`, `InterpolationWeightY`, `Local Interpolation`,
  `preview.respectsInstanceData`.

### M9.35 Match When Editing (builder, after the waves)

Adding a node on one master breaks compatibility with the others. This package gives the node
insert, node delete, set-start-node and reverse-contour commands an optional `matchLayers`
parameter that makes the same edit on every compatible layer in one undo step. The Edit menu
toggle is UI state and makes the window pass the parameter.

Rows: `edit.toggleMatchWhenEditing`.
Needs: none. Shares node and path command files with the Drawing packages; runs after them.
Files: the node and path commands in `crates/engine/src/cmd/`.
Tests: with the parameter, adding a node on one master keeps all masters compatible.
Measure: 100% of corpus glyphs stay compatible after a scripted add and delete.
Guesses: `matchLayers` covers four structural edits.

### M9.36 Designspace helpers (writer, wave 7)

The handbook's designspace helpers are missing. This package adds four commands in

`font.mergeFontsToMasters`.
Needs: none.
Files: `crates/engine/src/cmd/variation_tools.rs`.
Tests: one behaviour test each; Merge then compile equals the inputs at the masters.
Guesses: Merge Fonts to Masters takes the axes from the weight and width classes.

### M9.37 Glyph sources, influence, axis animation (builder, after the waves)

A glyph's sources cannot be switched off or inspected. This package adds an inactive flag per

### M9.38 Vertical metrics, `OVERLAP_COMPOUND` in variable fonts (builder, after the waves)

Variable fonts lack the vertical tables that static exports write. This package writes `vhea`
and `vmtx` at the origin when the static rule would, vertical phantom points per source in
`gvar`, and `VVAR` from the vertical advances (with the vertical origin map for CFF2, as
fontTools builds it). `OVERLAP_COMPOUND` is set where an oracle sets it; if neither does, the
flag stays off and the row says so.

Rows: `VVAR`, `vhea`, `vmtx`, `compile.variableOnlyTables`, `compile.gvarPhantomPoints`,
`compile.overlapFlags`, `compile.verticalMetrics`.
Needs: none. Runs before M9.39 (same files).
Files: `crates/compile/src/var/{mod,gvar,hvar,glyf,cff2}.rs`.
Tests: a two-master source with vertical metrics: `VVAR` and phantom deltas read back with skrifa
at a midpoint.
Measure: `oracle --corpus --variable` against fontmake and fontc on the sources with vertical
metrics; totals do not drop (fontc 103/35/20, fontmake 106/36/16).
